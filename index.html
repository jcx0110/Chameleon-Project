Control-Indexed Prospective Memory for Visuomotor Manipulation

A visuomotor policy that keeps look-alike histories apart, recalls the one the current decision needs, and turns it into a state ready for action.

Motivation

The clue disappears. The decision remains.

In long-horizon manipulation, the information that determines an action may appear long before the robot needs to act. At the decision point, the same visible scene can require different actions depending on its history. We call this gap observation–action delay.

Real-robot benchmark

Camo-Dataset

Each episode shows the evidence early, then hides, moves or repeats it until the scene no longer tells the robot what to do. At that aliased decision point, look-alike scenes call for different actions, so a policy can only succeed by recovering the right past.

UR5 arm with a Robotiq Hand-E gripper 2 RGB views, wrist and third-person 120 teleoperated demos per task Balanced over the hidden variable, so chance is exact

Scoring separates motor errors from memory errors: a policy can execute a clean grasp and still pick the wrong target.

MSR = P(M)
Manipulation success. A valid manipulation, whichever target it picks.
DSR = P(D | M)
Decision success. The history-correct target or subgoal, given a valid manipulation.
SR = P(M ∩ D)
End-to-end success. Both at once.

Evaluation

Memory changes what the robot can do.

Camo-Dataset reports manipulation success (MSR), history-correct decision success (DSR), and end-to-end success (SR) separately. Chameleon improves the decision—not only the motion.
